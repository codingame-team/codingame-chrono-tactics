Wood 1 League: You now command 3 units, unlock the PUSH ability (range 1, cooldown 2) to knock adjacent units into the abyss, and the outer ring of the arena degrades every 20 turns!

 The Goal

Outscore your opponent over 120 turns by capturing Chrono-Beacons and keeping your tactical squad alive on a crumbling grid arena.

 Rules

The game is played on a rotationally symmetric 11×11 grid. Coordinates follow the standard grid convention: x increases to the right, y increases downwards, and (0, 0) is the top-left corner. Each tile is one of:

  • 0: Void abyss (impassable; units cannot voluntarily move onto a 0 tile, and any unit ending up on a 0 tile is eliminated).
  • 1, 2, 3: Walkable floor tile with its current structural integrity.
  • #: Indestructible pillar (impassable obstacle).

Turn Resolution Order

  1. Simultaneous Movement (MOVE x y or WAIT): Each unit takes 1 orthogonal step along the shortest walkable path toward (x, y), never voluntarily stepping onto void (0) or pillar (#) tiles. If two units attempt to enter the same tile or swap positions, or if a unit's step is blocked by a stationary unit, the blocked units stay in place.
  2. Tactical Push (PUSH tx ty): All PUSH commands are first validated against post-movement positions (checking cooldown = 0 and that (tx, ty) is orthogonally adjacent to the acting unit, i.e. Manhattan distance 1), and every valid pusher immediately has its cooldown set to 2. Recorded pushes are then executed in unit ID order (Player 0's units, then Player 1's units). Any unit at (tx, ty) — friendly or opposing (pushing a friendly unit can move it an extra tile in the same turn) — is pushed 1 tile away in the pushing direction:
    • If pushed into the void (0) or outside the grid, the pushed unit is eliminated. If it belonged to the opponent, the pusher gains +15 bonus points!
    • If pushed into a pillar (#) or another unit, the target stays in place and its cooldown increases by 2 (stunned).
    Because all pushes are validated before effects are applied, if two adjacent units push each other on the same turn, both pushes are executed (and if either is slammed into an obstacle, its cooldown increases from 2 to 4).
  3. Tile Demolition (BOMB tx ty): If cooldown is 0 and the acting unit's Manhattan distance to (tx, ty) is 1 or 2, reduces the integrity of floor tile (tx, ty) by 1 and sets the acting unit's cooldown to 2. If multiple units bomb the same tile on the same turn, the integrity reductions are cumulative. If integrity reaches 0, the tile collapses into void: any beacon on it is destroyed and any unit standing on it is eliminated!
  4. Chrono-Storm Ring Collapse: Every 20 turns (turns 20, 40, 60, and 80), the outermost active ring of the arena degrades. A ring at radius r consists of all tiles whose Chebyshev distance from the center (5, 5) is max(|x - 5|, |y - 5|) = r, starting at r = 5 on turn 20 and shrinking inward by 1 every 20 turns (r = 5, 4, 3, 2). On that ring:
    • Each floor tile (1–3) loses 1 integrity, collapsing into void (0) if it reaches 0.
    • Each pillar (#) is cracked by the storm and turns into a walkable floor tile of integrity 1.
  5. Beacon Capture & Scoring: A unit standing on an active Chrono-Beacon captures it for its owner. Once captured, the beacon remains under that player's control even after the unit leaves the tile, until an opposing unit stands on it (transferring ownership) or its tile collapses into void. At the end of each turn, each player gains:
    • +2 points per controlled Chrono-Beacon,
    • +1 point per alive unit.
    If all units of a player are eliminated, the match ends immediately and the surviving player receives +20 bonus points per remaining alive unit.

Unexecutable Actions: Syntactically valid actions that cannot be executed (such as MOVE outside the grid or toward an obstacle or occupied tile, or BOMB/PUSH while cooldown > 0 or out of range) are simply ignored and do not cause defeat. Targeting a pillar or void tile with BOMB within range while cooldown = 0 has no effect on the tile but still triggers the 2-turn cooldown.

Victory Conditions
  • You have more points than your opponent at the end of the game (after 120 turns or when one squad is completely eliminated).
Defeat Conditions
  • You have fewer points than your opponent at the end of the game.
  • Your program does not respond within the allotted time or outputs a malformed/unrecognized command.

 Game Input & Output

Initialization Input

Line 1: 3 space-separated integers width, height and leagueLevel, the width and height of the grid (11×11) and the current Wood division (3 for Wood 3, 2 for Wood 2, 1 for Wood 1).

Input for One Game Turn

Line 1: an integer turn, the current turn number (1 to 120).

Next height lines: a string row of width characters representing one row of the grid (0 for void, 1–3 for floor tile integrity, or # for an indestructible pillar).

Next line: an integer unitCount, the total number of alive units on the grid.

Next unitCount lines: 5 space-separated integers unitId, owner, x, y and cooldown:

  • unitId: unique identifier of the unit.
  • owner: 0 if you own this unit (your units are always listed first), 1 if owned by your opponent.
  • x, y: grid coordinates of the unit.
  • cooldown: turns remaining before this unit can use a special action.

Next line: an integer beaconCount, the number of active Chrono-Beacons.

Next beaconCount lines: 3 space-separated integers bx, by and beaconOwner, the coordinates of the beacon and its owner (-1 for neutral, 0 for you, 1 for your opponent).

Output for One Game Turn

One line per alive unit you own (in the exact order they appear in the input), containing one movement command optionally followed by a special action:

  • MOVE x y to move the unit toward the integer target coordinates (x, y).
  • WAIT to keep the unit stationary.

A MOVE or WAIT command is optionally followed by a special action:

  • BOMB tx ty to bomb the tile at the integer target coordinates (tx, ty).
  • PUSH tx ty to push a unit at the integer target coordinates (tx, ty).

Example: MOVE 5 5 BOMB 6 5

You may optionally append MSG text at the end of a line to display a message in the viewer.

Constraints
width = 11, height = 11
1 ≤ unitCount ≤ 6
0 ≤ beaconCount ≤ 7
Response time for first turn ≤ 1000 ms
Response time for one turn ≤ 50 ms
Maximum number of turns: 120
