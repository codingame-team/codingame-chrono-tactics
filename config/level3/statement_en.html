Bronze+ League: You now command 3 units, unlock the PUSH tx ty ability (range 1, cooldown 2) to knock adjacent units into the abyss, and the outer ring of the arena degrades every 20 turns!

 The Goal

Outscore your opponent over 120 turns by capturing Chrono-Beacons and keeping your tactical squad alive on a crumbling grid arena.

 Rules

The game is played on a symmetric 11×11 grid where each cell is one of:

  • 0: Void abyss (impassable; any unit ending up on a 0 cell is eliminated).
  • 1, 2, 3: Walkable floor tile with its current structural integrity.
  • #: Indestructible pillar (impassable obstacle).

Turn Resolution Order

  1. Simultaneous Movement (MOVE x y): Each unit takes 1 orthogonal step along the shortest walkable path toward (x, y). If two units attempt to enter the same tile or swap positions, neither moves.
  2. Tactical Push (PUSH tx ty): If cooldown is 0 and (tx, ty) is orthogonally adjacent (Manhattan distance 1), any unit at (tx, ty) is pushed 1 cell away in the same direction:
    • If pushed into the void (0) or outside the grid, the pushed unit is eliminated and the pusher gains +15 bonus points!
    • If pushed into a pillar (#) or another unit, the target stays in place and its cooldown increases by 2 (stunned).
    Sets the acting unit's cooldown to 2.
  3. Tile Demolition (BOMB tx ty): If cooldown is 0 and the Manhattan distance to (tx, ty) is 1 or 2, reduces the integrity of tile (tx, ty) by 1. If integrity reaches 0, the tile collapses into void: any beacon on it is destroyed and any unit standing on it is eliminated! Sets the acting unit's cooldown to 2.
  4. Chrono-Storm Ring Collapse: Every 20 turns (turns 20, 40, 60, 80, 100), the outermost active ring of the arena loses 1 integrity (pillars on that ring turn into integrity 1 floor tiles).
  5. Beacon Capture & Scoring: A unit standing on an active Chrono-Beacon captures it for its owner. At the end of each turn, each player gains:
    • +2 points per controlled Chrono-Beacon,
    • +1 point per alive unit.
    If all units of a player are eliminated, the match ends immediately and the surviving player receives +20 bonus points per remaining alive unit.
Victory Conditions
  • You have more points than your opponent at the end of the game (after 120 turns or when one squad is completely eliminated).
Defeat Conditions
  • You have fewer points than your opponent at the end of the game.
  • Your program does not respond within the allotted time or outputs an unrecognized command.

 Game Input & Output

Initialization Input

Line 1: 3 space-separated integers width, height and leagueLevel, the width and height of the grid (11×11) and the current league level (1, 2 or 3).

Input for One Game Turn

height lines: a string row of width characters representing one row of the grid (0 for void, 1-3 for floor integrity, or # for an indestructible pillar).

Next line: an integer unitCount, the total number of alive units on the grid.

Next unitCount lines: 5 space-separated integers unitId, owner, x, y and cooldown:

  • unitId: unique identifier of the unit.
  • owner: 0 if you own this unit (your units are always listed first), 1 if owned by your opponent.
  • x, y: grid coordinates of the unit.
  • cooldown: turns remaining before this unit can use a special action.

Next line: an integer beaconCount, the number of active Chrono-Beacons.

Next beaconCount lines: 3 space-separated integers bx, by and beaconOwner, the coordinates of the beacon and its owner (-1 for neutral, 0 for you, 1 for your opponent).

Output for One Game Turn

One line per alive unit you own (in the exact order they appear in the input), containing one movement command optionally followed by a special action:

  • MOVE x y (or WAIT) where x and y are integer grid coordinates, optionally followed by:
  • BOMB tx ty where tx and ty are integer target coordinates at Manhattan distance 1 or 2 (requires cooldown = 0)
  • PUSH tx ty where tx and ty are integer target coordinates at Manhattan distance 1 (requires cooldown = 0)

You may optionally append MSG text at the end of a line to display a message in the viewer. Example: MOVE 5 5 BOMB 6 5

Constraints
width = 11, height = 11
1 ≤ unitCount ≤ 6
0 ≤ beaconCount ≤ 7
Response time for first turn ≤ 1000 ms
Response time for one turn ≤ 50 ms
Maximum number of turns: 120
