Wood 3 League: Command 1 unit to capture Chrono-Beacons across the arena. Special tactical abilities will unlock in higher divisions.

 The Goal

Outscore your opponent over 120 turns by capturing Chrono-Beacons on a grid arena.

 Rules

The game is played on a rotationally symmetric 11×11 grid. Coordinates follow the standard grid convention: x increases to the right, y increases downwards, and (0, 0) is the top-left corner. Each tile is one of:

  • 0: Void abyss (impassable; units cannot voluntarily move onto a 0 tile).
  • 1, 2, 3: Walkable floor tile (tile integrity values have no effect in Wood 3, as tiles do not crumble in this division).
  • #: Indestructible pillar (impassable obstacle).

Turn Resolution Order

  1. Simultaneous Movement (MOVE x y or WAIT): Each unit takes 1 orthogonal step along the shortest walkable path toward (x, y), never voluntarily stepping onto void (0) or pillar (#) tiles. If two units attempt to enter the same tile or swap positions, or if a unit's step is blocked by a stationary unit, the blocked units stay in place.
  2. Beacon Capture & Scoring: A unit standing on an active Chrono-Beacon captures it for its owner. Once captured, the beacon remains under that player's control even after the unit leaves the tile, until an opposing unit stands on it (transferring ownership). At the end of each turn, each player gains:
    • +2 points per controlled Chrono-Beacon,
    • +1 point per alive unit.

Unexecutable Actions: Syntactically valid actions that cannot be executed (such as MOVE outside the grid or toward an obstacle or occupied tile) are simply ignored and do not cause defeat.

Victory Conditions
  • You have more points than your opponent at the end of the game (after 120 turns).
Defeat Conditions
  • You have fewer points than your opponent at the end of the game.
  • Your program does not respond within the allotted time or outputs a malformed/unrecognized command.

 Game Input & Output

Initialization Input

Line 1: 3 space-separated integers width, height and leagueLevel, the width and height of the grid (11×11) and the current Wood division (3 for Wood 3, 2 for Wood 2, 1 for Wood 1).

Input for One Game Turn

Line 1: an integer turn, the current turn number (1 to 120).

Next height lines: a string row of width characters representing one row of the grid (0 for void, 1–3 for floor tile integrity, or # for an indestructible pillar).

Next line: an integer unitCount, the total number of alive units on the grid.

Next unitCount lines: 5 space-separated integers unitId, owner, x, y and cooldown:

  • unitId: unique identifier of the unit.
  • owner: 0 if you own this unit (your units are always listed first), 1 if owned by your opponent.
  • x, y: grid coordinates of the unit.
  • cooldown: always 0 in Wood 3, as special actions are unavailable in this division.

Next line: an integer beaconCount, the number of active Chrono-Beacons.

Next beaconCount lines: 3 space-separated integers bx, by and beaconOwner, the coordinates of the beacon and its owner (-1 for neutral, 0 for you, 1 for your opponent).

Output for One Game Turn

One line per alive unit you own (in the exact order they appear in the input), containing one movement command:

  • MOVE x y to move the unit toward the integer target coordinates (x, y).
  • WAIT to keep the unit stationary.

Example: MOVE 5 5

You may optionally append MSG text at the end of a line to display a message in the viewer.

Constraints
width = 11, height = 11
unitCount = 2
beaconCount = 7
Response time for first turn ≤ 1000 ms
Response time for one turn ≤ 50 ms
Maximum number of turns: 120
