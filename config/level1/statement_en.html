Wood 2 League: Command 1 unit to capture Chrono-Beacons across the arena. Special actions (BOMB and PUSH) will unlock in higher leagues.

 The Goal

Outscore your opponent over 120 turns by capturing Chrono-Beacons and keeping your tactical squad alive on a crumbling grid arena.

 Rules

The game is played on a symmetric 11×11 grid where each cell is one of:

  • 0: Void abyss (impassable; any unit ending up on a 0 cell is eliminated).
  • 1, 2, 3: Walkable floor tile with its current structural integrity.
  • #: Indestructible pillar (impassable obstacle).

Turn Resolution Order

  1. Simultaneous Movement (MOVE x y): Each unit takes 1 orthogonal step along the shortest walkable path toward (x, y). If two units attempt to enter the same tile or swap positions, neither moves.
  2. Beacon Capture & Scoring: A unit standing on an active Chrono-Beacon captures it for its owner. At the end of each turn, each player gains:
    • +2 points per controlled Chrono-Beacon,
    • +1 point per alive unit.

 Game Input & Output

Initialization Input
Line 1: width height leagueLevel (11 11 and the current league level).
Input for One Game Turn
  • Next height lines: string row of length width (0, 1-3, or #).
  • Next line: unitCount, the total number of alive units.
  • Next unitCount lines: unitId owner x y cooldown (owner is always 0 for your units, listed first, and 1 for opponent units).
  • Next line: beaconCount, the number of active beacons.
  • Next beaconCount lines: bx by beaconOwner (-1=neutral, 0=yours, 1=opponent).
Output for One Game Turn
Output one line per alive unit you own (in the exact order they appear in the input):
  • MOVE x y (or WAIT) optionally followed by:
Example: MOVE 5 5 BOMB 6 5
